使用 union  或 union all操作符
# union all
该操作符用于连个结果集的并集,不会去重
```
# 1. union all 就是将两个结果合并,不会去重
SELECT ename, sal,job FROM emp WHERE sal > 2500
UNION ALL
SELECT ename ,sal ,job FROM emp WHERE job ='MANAGER';
```
![[union all.png]]
# union 
会去重
```
SELECT ename, sal,job FROM emp WHERE sal > 2500
UNION
SELECT ename ,sal ,job FROM emp WHERE job ='MANAGER';
```
