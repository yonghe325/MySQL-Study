在默认情况下,当两个表查询时,规则如下
1. 从第一张表中,取出一行 和 第二张表的每一行进行组合
返回结果\[含有两张表的所有列]
2. 一共返回的记录数 = 第一张表的行数 * 第二张表的行数
3. 这样多表查询的返回结果 称为 笛卡尔集
4. 解决这个问题的关键就是要进行分析,然后写出正确的过滤条件where
```
# 未设定过滤条件,出现笛卡尔集
SELECT * FROM emp,dept;
```
![[多表查询-笛卡尔集.png]]
```
# 设定正确的过滤条件
SELECT * FROM emp,dept
	WHERE emp.`deptno` = dept.`depton`;
```
![[多表查询-设定正确的过滤条件.png]]
# 查询多表同时存在列名
```
SELECT ename,sal,dname,deptno
	FROM emp,dept
	WHERE emp.deptno = dept.depton;
# emp,dept量表同时存在deptno列
# 导致异常 : ambiguous(模糊)

# 正确写法
SELECT ename,sal,dname,emp.deptno
	FROM emp,dept
	WHERE emp.deptno = dept.depton;
```
# 条件查询
1. 先写简单的sql语句
2. 然后加入过滤条件
```
# 如何显示部门号为10的部门,员工和工资
SELECT ename,sal,dname,emp.deptno
	FROM emp,dept
	WHERE emp.deptno = dept.deptno AND emp.`deptno` = 10;
	
# 显示各个员工的的姓名 ,工资,及其工资的级别 
SELECT  ename,sal,grade 
	FROM emp,salgrade
	WHERE sal>losal AND sal<hisal;
## 该方法不包括临界值
SELECT ename,sal,grade
	FROM emp,salgrade
	WHERE sal BETWEEN losal AND hisal;
## 使用BETWEEN AND ,BETWEEN AND 取值包含临界值
# 显示雇员名,工资及其所在的部门,并按部门排序
SELECT ename AS 姓名,sal AS 工资,dname AS 部门名称 FROM emp,dept
	WHERE emp.`deptno` = dept.`deptno`
	ORDER BY emp.`deptno` DESC;

```
