# 左外连接 : 左侧的表完全显示表
```
# 使用左外链接,
## 所有人的成绩如果没有成绩,也要显示该人的姓名和id号,成绩显示为空
## 不使用外连接,通过过滤条件查询
## 无法显示非匹配条件
SELECT stu.id, `name` , grade
	FROM stu ,exam
	WHERE stu.`id` = exam.`id`

## 左外连接
SELECT `name`,stu.`id`,grade
	FROM stu LEFT JOIN exam
	ON stu.`id` = exam.`id`;
```
# 右外连接 : 右侧的表完全显示
```
## 右外连接
SELECT `name`,stu.`id`,grade
	FROM stu RIGHT JOIN exam
	ON stu.`id` = exam.`id`;
```
