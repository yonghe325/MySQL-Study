| MySQL隔离级别             | 脏读  | 不可重复读 | 幻读  | 加锁读 |
| --------------------- | --- | ----- | --- | --- |
| 读未提交 Read uncommitted | v   | v     | v   | 不加锁 |
| 读已提交 Read committed   | x   | v     | v   | 不加锁 |
| 可重复读 Reapeatable read | x   | x     | x   | 不加锁 |
| 可串行化 Serializable     | x   | x     | x   | 加锁  |
# 设置隔离级别
```
SET SESSION TRANSACTION ISOLATION LEVEL <隔离级别>;
```
