# 概念
MYSQL隔离级别定义了事务与事务之间的隔离程度
# 解释 : 每个链接看到的数据不同
多个连接开启各自事务操作数据库中数据时，
数据库系统要负责隔离操作
以保证各个连接在获取数据时的准确性
# 常见问题
如果不考虑隔离性,可能会有以下问题 :
## 脏读 dirty read
A事务正在修改数据但未提交，此时B事务去读取此条数据，B事务读取的是未提交的数据，A事务回滚
即当一个事务读取另一个事务尚未提交的修改时
发生脏读
## 不可重复读 nonrepeatable read
A事务中两次查询同一数据的内容不同，B事务间在A事务两次读取之间更改了此条数据

同一查询在同一事物中多次进行
由于其他提交事务所做出的==修改或删除==
==每次返回不同的结果==
发生不可重复读
## 幻读
在同一事务中两次相同查询数据的条数不一致
例如第一次查询查到5条数据，第二次查到8条数据
这是因为在两次查询的间隙，另一个事务插入了3条数据

同一查询在同一事物中多次进行
由于其他提交事务所做出的==插入操作==
==每次返回不同的结果==
发生不可重复读
