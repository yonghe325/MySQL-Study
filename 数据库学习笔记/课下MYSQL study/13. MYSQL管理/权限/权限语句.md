# 授予权限
```
grant <权限> on <数据库name>.<表_name>,... to '<用户名>'@'\<IP地址>' 
	[IDENTIFIED BY '密码']
	(with grant option允许被授予权限用户在向其他用户授权);
```
1. 多个权限用逗号隔开
2. 通配符选择 <数据库name>.<表_name>,...
+ \*.\* : 本系统所有库和表
+ <数据库name>.* : 某个数据库的所有表 
3. IDENTIFIED BY '密码' 可以省略,也可以写出 
+ 如果用户存在,就是修改用户密码
+ 如果不用户存在,就是创建用户并设置密码
# 回收权限
```
revoke <权限> on <数据库name>.<表_name>,... from '<用户名>'@'\<IP地址>' 
```
