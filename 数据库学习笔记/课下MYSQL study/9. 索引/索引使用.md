# 查看表是否有索引
```
SHOW INDEX FROM <table_name>;
```
# 添加索引
若何选择索引 : 
如果某列的值不会重复
优先使用unique索引
否则使用普通索引
## 主键索引
```
ALTER TABLE <表名> 
	ADD PRIMARY KEY (<列名>);
```
## 唯一索引
```
CREATE UNIQUE INDEX <索引名> ON <表名>(<字段名>);
```
![[唯一索引.png]]
## 普通索引
```
CREATE UNIQUE INDEX <索引名> ON <表名>(<字段名>);
```
或
```
ALTER TABLE <索引名> 
	ADD <表名> (<字段名>);
```   
# 删除索引
```
DROP INDEX <索引名> ON index_stu;
```
## 删除主键索引
```
ALTER TABLE <主键索引名> DROP PRIMARY KEY;
```
