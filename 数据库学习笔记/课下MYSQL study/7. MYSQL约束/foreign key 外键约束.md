约束列的值在被约束列必须已经存在
```
FOREIGN KEY (从表被外键约束列) REFERENCES 主表名(主表列)
```

==外键定义 需要定义在 从表上==
用于定义主表与从表之间的关系
主表必须有主键约束或unique约束
即 外键约束列的主表列不能重复

## 当定义外键列时
==外键列数据必须在主表的主键列上存在或为NULL==

## 当==从表==插入数据时
==若外键列的插入数据在主表的主键列上不存在
则插入不会成功==

## 当==主表删除==数据时
若从表存在外键,则==先==需要删除从表的外键列
才能删除主表的数据
